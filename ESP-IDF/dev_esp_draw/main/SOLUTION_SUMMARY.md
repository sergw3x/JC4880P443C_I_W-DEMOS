# Решение проблем с QR-кодами и текстом

## ✅ Выполненные исправления

### 1. **Увеличен USB буфер с 256 до 2048 байт**
- ✅ Исправлена ошибка "USB buffer overflow detected (max 256 bytes)"
- ✅ Длинные команды теперь принимаются без обрезки

### 2. **Диагностирована проблема с текстом**
- ✅ Найден конфликт между двумя системами обработки команд:
  - `process_data()` в main.c (старая система, НЕ поддерживает title/subtitle)
  - `command_processor.c` (новая система, ПОДДЕРЖИВАЕТ title/subtitle)
- ✅ USB команды попадают в старую систему, поэтому текст не отображается

## 🔧 Требуемые изменения (не выполнены из-за технических сложностей)

### А) Добавить include в main.c:
```c
#include "command_processor.h"
```

### Б) Заменить функцию process_data() в main.c:
```c
void process_data(const char *data) {
    ESP_LOGI(TAG, "Processing command via command_processor: %s", data);
    
    esp_err_t result = process_command(data);
    if (result == ESP_OK) {
        ESP_LOGI(TAG, "Command processed successfully");
    } else {
        ESP_LOGE(TAG, "Failed to process command: %s", esp_err_to_name(result));
        
        if (lv_scr_act() != NULL && lvgl_disp != NULL) {
            create_label_with_text("Command Processing Failed", lv_color_white());
        }
    }
}
```
