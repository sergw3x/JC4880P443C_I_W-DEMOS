# Реализация поддержки размера шрифта в QR+Text командах

## Обзор

Добавлена поддержка настраиваемого размера шрифта для текста, отображаемого вместе с QR кодами через JSON команду `qr_text`.

## Изменения в структуре данных

### Обновлена структура `qr_text_params_t` в `qr_text_commands.h`
```c
typedef struct {
    char* qr_data;
    char* text;
    lv_color_t qr_color;
    lv_color_t bg_color;
    lv_color_t text_color;
    uint16_t font_size;  // НОВОЕ ПОЛЕ
} qr_text_params_t;
```

## Новая функциональность

### 1. Функция выбора шрифта `get_font_by_size()`
- Поддерживаемые размеры: 10px, 14px, 16px, 18px (по умолчанию), 20px, 24px, 28px, 32px
- Автоматический выбор ближайшего размера для промежуточных значений
- Валидация диапазона (10-32px)

### 2. Обновлен JSON парсер `parse_qr_text_json()`
- Добавлено извлечение поля `font_size` из JSON
- Валидация диапазона с автоматической коррекцией
- Значение по умолчанию: 18px

### 3. Модифицирована функция отображения `create_qr_with_text()`
- Применение выбранного шрифта к текстовой метке
- Логирование используемого размера шрифта

## Формат JSON команды

### Базовый формат
```json
{
  "type": "qr_text",
  "data": "QR_CODE_DATA_HERE",
  "text": "Text to display"
}
```

### С указанием размера шрифта
```json
{
  "type": "qr_text",
  "data": "https://example.com",
  "text": "Visit our website!",
  "font_size": 24
}
```

### Полный формат со всеми опциями
```json
{
  "type": "qr_text",
  "data": "WIFI:T:WPA;S:MyNetwork;P:password123;;",
  "text": "WiFi Network\nScan to connect",
  "qr_color": "#FF0000",
  "bg_color": "#FFFF00", 
  "text_color": "#0000FF",
  "font_size": 20
}
```

## Поддерживаемые размеры шрифтов

| Размер (px) | Шрифт LVGL             | Описание                      |
|-------------|------------------------|-------------------------------|
| 10          | lv_font_montserrat_10  | Очень маленький текст         |
| 14          | lv_font_montserrat_14  | Маленький текст               |
| 16          | lv_font_montserrat_16  | Малый-средний текст           |
| 18          | lv_font_montserrat_18  | Стандартный (по умолчанию)    |
| 20          | lv_font_montserrat_20  | Средний-большой текст         |
| 24          | lv_font_montserrat_24  | Большой текст                 |
| 28          | lv_font_montserrat_28  | Очень большой текст           |
| 32          | lv_font_montserrat_32  | Максимальный размер           |

## Автоматическая коррекция размера

- **Меньше 10px**: автоматически устанавливается 10px
- **Больше 32px**: автоматически устанавливается 32px  
- **Промежуточные значения**: выбирается ближайший доступный размер

## Примеры использования

### Маленький шрифт для компактного отображения
```json
{
  "type": "qr_text",
  "data": "product-12345", 
  "text": "Product ID",
  "font_size": 10
}
```

### Большой шрифт для улучшенной читаемости
```json
{
  "type": "qr_text",
  "data": "https://example.com",
  "text": "SCAN ME FOR INFO", 
  "font_size": 32
}
```

### Средний шрифт для баланса
```json
{
  "type": "qr_text",
  "data": "WIFI:T:WPA;S:MyNetwork;P:password123;;",
  "text": "WiFi Credentials\nScan to connect",
  "font_size": 20
}
```

## Обработка ошибок

- Некорректные значения размера автоматически корректируются
- Логирование предупреждений о коррекции размера
- Сохранение работоспособности при любых входных данных

## Совместимость

- Обратная совместимость с существующими командами (без поля font_size)
- Значение по умолчанию 18px обеспечивает прежний вид
- Интеграция с существующими цветовыми опциями

## Тестирование

Примеры команд для тестирования:

1. **Минимальный размер**: `{"type":"qr_text","data":"test","text":"Small","font_size":10}`
2. **Максимальный размер**: `{"type":"qr_text","data":"test","text":"Large","font_size":32}`
3. **Коррекция вверх**: `{"type":"qr_text","data":"test","text":"Fixed","font_size":5}`
4. **Коррекция вниз**: `{"type":"qr_text","data":"test","text":"Fixed","font_size":50}`
5. **Промежуточный**: `{"type":"qr_text","data":"test","text":"Medium","font_size":19}`
