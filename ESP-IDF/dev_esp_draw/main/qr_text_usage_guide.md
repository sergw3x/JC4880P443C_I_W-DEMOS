# QR-код с текстовыми подписями - Руководство по использованию

## Обзор

Теперь QR-коды могут отображаться с текстовыми подписями (заголовком и подзаголовком), что делает их более информативными и профессиональными.

## Примеры JSON команд

### 1. Базовый QR-код (как и раньше)
```json
{
  "command": "qr",
  "data": "https://example.com"
}
```

### 2. QR-код с цветовой настройкой
```json
{
  "command": "qr", 
  "data": "https://example.com",
  "qr_color": "#FF0000",
  "bg_color": "#FFFFFF"
}
```

### 3. QR-код с заголовком
```json
{
  "command": "qr",
  "data": "https://example.com", 
  "title": "Скачайте наше приложение"
}
```

### 4. QR-код с подзаголовком
```json
{
  "command": "qr",
  "data": "https://example.com",
  "subtitle": "Отсканируйте QR код для загрузки"
}
```

### 5. Полный QR-код с текстовыми подписями
```json
{
  "command": "qr",
  "data": "https://example.com/app-download", 
  "title": "📱 Мобильное приложение",
  "subtitle": "Скачайте с App Store или Google Play",
  "qr_color": "#2563EB", 
  "bg_color": "#F8FAFC"
}
```

### 6. QR-код для Wi-Fi сети
```json
{
  "command": "qr",
  "data": "WIFI:T:WPA;S:MyWiFiNetwork;P:password123;;",
  "title": "🔐 Подключение к Wi-Fi", 
  "subtitle": "Отсканируйте для подключения к сети MyWiFiNetwork"
}
```

## Новые параметры

### `title` (опциональный)
- **Тип**: Строка
- **Описание**: Заголовок, отображаемый над QR-кодом
- **Особенности**: 
  - Автоматически переносит длинные строки
  - Использует крупный шрифт (Montserrat 24px)
  - Цвет соответствует цвету QR-кода
- **Пример**: "📱 Мобильное приложение"

### `subtitle` (опциональный) 
- **Тип**: Строка
- **Описание**: Подзаголовок, отображаемый под QR-кодом
- **Особенности**:
  - Также поддерживает автоматический перенос строк
  - Использует средний шрифт (Montserrat 16px)
  - Цвет немного светлее основного цвета QR-кода
- **Пример**: "Отсканируйте QR код для загрузки"

## Компоновка элементов

Элементы размещаются в следующем порядке:
1. **Заголовок** (если указан) - в верхней части экрана
2. **QR-код** - по центру, занимает ~60% высоты экрана  
3. **Подзаголовок** (если указан) - в нижней части

### Размеры элементов:
- **Контейнер**: 95% ширины, 90% высоты экрана
- **QR-код**: 60% от высоты экрана (максимум)
- **Отступы**: 20px между элементами, 10px от краев

## Обратная совместимость

- Все существующие JSON команды продолжают работать без изменений
- Параметры `title` и `subtitle` полностью опциональные
- Старая функция `create_qr_code()` автоматически использует новую реализацию с пустыми подписями

## Обработка ошибок

Функция корректно обрабатывает:
- Пустые или отсутствующие текстовые подписи
- Ошибки создания LVGL объектов  
- Недостаточно места на экране для всех элементов
- Некорректные данные QR-кода

В случае ошибок показывается сообщение "QR Code Generation Failed".

## Логирование

Добавлено подробное логирование для отладки:
- Парсинг текстовых подписей
- Создание каждого элемента UI
- Ошибки и успешные операции

Логи доступны через тег `qr_commands` в ESP-IDF logging system.
